# 橙子课表 OrangeOrganize — 官网

橙子课表（OrangeOrganize）官方下载页与产品介绍站。纯静态单页站点，无构建工具、无外部依赖，双击 `index.html` 即可预览，也可直接部署到任意静态托管（GitHub Pages / Vercel / Nginx / 对象存储）。

**在线内容：** 产品介绍 · 核心特性 · APK 下载 · 常见问题

## 📁 项目结构

```
OrangeOrganize/
├── index.html                      # 单页站点（结构 + 样式 + 交互脚本，全部内联）
├── DESIGN.md                       # 设计说明：配色、版式、交互规范
├── assets/
│   └── logo.svg                    # 品牌 Logo
├── downloads/
│   └── orange-organize-v1.4.0.apk  # 当前发布的安装包
└── README.md
```

## ✨ 站点内容

- **Hero 首屏** — 品牌名、一句话简介、下载 / 查看特性入口，以及「轻便简洁 / 零广告 / 免登录 / Android 8.0+」标签
- **核心特性** — 轻量（安装包 < 15MB）、简洁（Material 3 + 零广告）、快速导入（支持 `.ics` 日历文件）、实用（课前提醒 + 教室显示）
- **下载区块** — 当前版本 `v1.4.0`，含安装提示（需允许「安装未知来源应用」）
- **FAQ 手风琴** — 联网/账号、数据安全、课表导入、问题反馈、系统版本、收费情况

## 🔧 技术说明

- **单文件实现**：HTML / CSS / JS 全部内联于 `index.html`，样式通过 CSS 变量（`--color-*`）集中管理
- **响应式**：移动优先，断点 `<640px` 单列 / `640–1024px` 两列 / `>1024px` 居中留白
- **移动端**：`<992px` 显示汉堡菜单，触控点击区 ≥ 44px
- **交互**：导航栏滚动阴影、滚动到可视区淡入、FAQ 单项展开、平滑锚点滚动
- **无障碍**：适配 `prefers-reduced-motion`，正文文字对比度符合设计色板

详细配色与版式规范见 [DESIGN.md](DESIGN.md)。

## 🚀 发布新版本

替换安装包时请同步更新站点：

1. 将新 APK 放入 `downloads/`，命名沿用 `orange-organize-v<版本号>.apk`
2. 更新 `index.html` 中的下载链接 `href` 与页面显示的版本号文本
3. 若旧版本不再提供，删除 `downloads/` 下的旧文件，避免仓库体积膨胀
